# User Impersonation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let sysadmins impersonate non-sysadmin users via a confirmation dialog + persistent banner, with every action during impersonation audited under both IDs.

**Architecture:** Enable better-auth's admin plugin for the session-swap primitive. Layer a NestJS controller in front of it to enforce the "target ≠ sysadmin" rule and emit audit-log start/stop events. Audit-log gains an `impersonated_by_id` column carried on every record written during impersonation. Frontend gets a confirmation dialog at entry points (UsersTable row action + UserForm button) and a persistent amber banner mounted at the router root.

**Tech Stack:** NestJS 11 · better-auth v1.x with `admin` plugin · Drizzle ORM · React 19 · TanStack Router · CASL 6.

**Spec:** `docs/superpowers/specs/2026-06-09-user-impersonation-design.md` (commit `ca6255f`)

This module wraps better-auth's `auth.api.impersonateUser` and `auth.api.stopImpersonating`. The wrapper:
1. Rejects with 403 when target user's role is `sysadmin`.
2. Forwards better-auth's `Set-Cookie` headers to the client.
3. Emits an audit-log row (`entity_type = 'user_impersonation'`, action `start` or `stop`) inside a transaction.

- [ ] **Step 1: Service skeleton**

```ts
// user-impersonation.service.ts
import { ForbiddenException, Inject, Injectable, NotFoundException } from '@nestjs/common';
import { eq } from 'drizzle-orm';

import { type Auth, BETTER_AUTH } from '../../infrastructure/auth/better-auth.js';
import { type AuthenticatedUser } from '../../infrastructure/auth/auth.types.js';
import { DRIZZLE, type DrizzleDb } from '../../infrastructure/database/client.js';
import { user as userTable } from '../../infrastructure/database/schema/users.js';
import { AuditLogService } from '../audit-log/audit-log.service.js';

@Injectable()
export class UserImpersonationService {
  constructor(
    @Inject(BETTER_AUTH) private readonly auth: Auth,
    @Inject(DRIZZLE) private readonly db: DrizzleDb,
    private readonly audit: AuditLogService,
  ) {}

  /**
   * Starts impersonation: rejects sysadmin targets, then delegates the
   * session swap to better-auth's admin plugin. Returns the response headers
   * (Set-Cookie etc.) so the controller can forward them.
   */
  async start(actingUser: AuthenticatedUser, targetUserId: string, headers: Headers): Promise<Response> {
    if (actingUser.role !== 'sysadmin') {
      throw new ForbiddenException({ error: { code: 'FORBIDDEN', message: 'Only sysadmins may impersonate.' } });
    }
    const [target] = await this.db
      .select({ id: userTable.id, role: userTable.role })
      .from(userTable)
      .where(eq(userTable.id, targetUserId))
      .limit(1);
    if (!target) throw new NotFoundException({ error: { code: 'NOT_FOUND', message: 'User not found.' } });
    if (target.role === 'sysadmin') {
      throw new ForbiddenException({ error: { code: 'FORBIDDEN', message: 'Cannot impersonate another sysadmin.' } });
    }

    // Delegate session swap. The exact better-auth API surface for impersonation
    // is `auth.api.impersonateUser({ body: { userId }, headers, asResponse: true })`.
    // `asResponse: true` returns a Web Fetch Response we can hand back to the controller.
    const response = await this.auth.api.impersonateUser({
      body: { userId: targetUserId },
      headers,
      asResponse: true,
    });

    await this.db.transaction(async (tx) => {
      await this.audit.record({
        tx,
        entityType: 'user_impersonation',
        entityId: targetUserId,
        action: 'create',
        userId: actingUser.id,
        impersonatedById: null,
        before: null,
        after: { startedAt: new Date().toISOString() },
      });
    });

    return response;
  }

  async stop(actingUser: AuthenticatedUser, headers: Headers): Promise<Response> {
    if (!actingUser.impersonatedBy) {
      throw new ForbiddenException({ error: { code: 'FORBIDDEN', message: 'Not currently impersonating.' } });
    }
    const response = await this.auth.api.stopImpersonating({ headers, asResponse: true });

    await this.db.transaction(async (tx) => {
      await this.audit.record({
        tx,
        entityType: 'user_impersonation',
        entityId: actingUser.id, // the user being impersonated
        action: 'delete',
        userId: actingUser.impersonatedBy as string,
        impersonatedById: null,
        before: null,
        after: { stoppedAt: new Date().toISOString() },
      });
    });

    return response;
  }
}
```

**Note on `action`:** the `audit_log.action` enum currently allows `create`/`update`/`delete`/`move`/`deactivate`/`reactivate`/`password_reset_triggered`. We re-use `create` for start, `delete` for stop. (Adding `start`/`stop` to the enum is a larger schema change; the spec accepts re-use for Phase A.)

// user-impersonation.controller.ts
import { Body, Controller, Headers as NestHeaders, Post, Req, Res } from '@nestjs/common';
import type { FastifyReply, FastifyRequest } from 'fastify';

import { CurrentUser } from '../../infrastructure/auth/current-user.decorator.js';
import { type AuthenticatedUser } from '../../infrastructure/auth/auth.types.js';

import { UserImpersonationService } from './user-impersonation.service.js';

@Controller()
export class UserImpersonationController {
  constructor(private readonly service: UserImpersonationService) {}

  @Post('admin/impersonate-user')
  async start(
    @CurrentUser() user: AuthenticatedUser,
    @Body() body: { userId: string },
    @Req() req: FastifyRequest,
    @Res({ passthrough: false }) reply: FastifyReply,
  ): Promise<void> {
    const headers = new Headers();
    for (const [k, v] of Object.entries(req.headers)) {
      if (typeof v === 'string') headers.set(k, v);
    }
    const response = await this.service.start(user, body.userId, headers);
    response.headers.forEach((value, key) => reply.header(key, value));
    reply.status(response.status).send(await response.json().catch(() => null));
  }

  @Post('admin/stop-impersonating')
  async stop(
    @CurrentUser() user: AuthenticatedUser,
    @Req() req: FastifyRequest,
    @Res({ passthrough: false }) reply: FastifyReply,
  ): Promise<void> {
    const headers = new Headers();
    for (const [k, v] of Object.entries(req.headers)) {
      if (typeof v === 'string') headers.set(k, v);
    }
    const response = await this.service.stop(user, headers);
    response.headers.forEach((value, key) => reply.header(key, value));
    reply.status(response.status).send(await response.json().catch(() => null));
  }
}

import { useMutation, useQueryClient } from '@tanstack/react-query';

import * as api from '../api/impersonation.api.js';

export function useStartImpersonating() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: api.startImpersonating,
    onSuccess: () => {
      // Clear all queries — the impersonated user has different visibility.
      void qc.invalidateQueries();
    },
  });
}

export function useStopImpersonating() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: api.stopImpersonating,
    onSuccess: () => {
      void qc.invalidateQueries();
    },
  });
}

```tsx
// ConfirmImpersonateDialog.tsx
import * as React from 'react';
import { useTranslation } from 'react-i18next';

import {
  Button,
  Dialog,
  DialogContent,
  DialogFooter,
  DialogHeader,
  DialogTitle,
} from '@/shared/ui';

import { useStartImpersonating } from '../lib/hooks.js';

export interface ConfirmImpersonateDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  targetUser: { id: string; name: string | null; email: string };
}

export function ConfirmImpersonateDialog({
  open,
  onOpenChange,
  targetUser,
}: ConfirmImpersonateDialogProps): React.ReactElement {
  const { t } = useTranslation();
  const mut = useStartImpersonating();

  const onConfirm = (): void => {
    mut.mutate(targetUser.id, {
      onSuccess: () => {
        onOpenChange(false);
        // The banner will pick up the session change; no manual navigation.
      },
    });
  };

  const displayName = targetUser.name ?? targetUser.email;

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>
            {t('admin.users.impersonate.confirmTitle', { name: displayName })}
          </DialogTitle>
        </DialogHeader>
        <p className="text-on-surface-variant">
          {t('admin.users.impersonate.confirmBody')}
        </p>
        <DialogFooter>
          <Button variant="outline" onClick={() => onOpenChange(false)} disabled={mut.isPending}>
            {t('common.cancel')}
          </Button>
          <Button onClick={onConfirm} disabled={mut.isPending}>
            {t('admin.users.impersonate.confirm')}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

```tsx
// ImpersonationBanner.tsx
import { TriangleAlert } from 'lucide-react';
import * as React from 'react';
import { useTranslation } from 'react-i18next';

import { useSession } from '@/features/auth-by-email';
import { useStopImpersonating } from '@/features/user-impersonation';
import { Button } from '@/shared/ui';

/**
 * Mounted at the router root. Renders a sticky amber banner whenever the
 * current session was created via admin impersonation. The session payload
 * carries `impersonatedBy` (the sysadmin's user ID) when this is the case.
 */
export function ImpersonationBanner(): React.ReactElement | null {
  const { t } = useTranslation();
  const session = useSession();
  const mut = useStopImpersonating();

  const sessionRecord = session.data?.session as { impersonatedBy?: string | null; expiresAt?: string } | undefined;
  const userRecord = session.data?.user as { name?: string | null; email?: string } | undefined;
  if (!sessionRecord?.impersonatedBy) return null;

  const minutes = sessionRecord.expiresAt
    ? Math.max(0, Math.floor((new Date(sessionRecord.expiresAt).getTime() - Date.now()) / 60_000))
    : 0;

  return (
    <div
      role="status"
      className="sticky top-0 z-40 flex items-center justify-between gap-3 border-b border-warning bg-warning-container px-4 py-2 text-sm text-on-warning-container"
    >
      <div className="flex items-center gap-2">
        <TriangleAlert className="size-4" aria-hidden />
        <span>
          {t('admin.users.impersonate.banner', {
            name: userRecord?.name ?? userRecord?.email ?? '',
            email: userRecord?.email ?? '',
            minutes,
          })}
        </span>
      </div>
      <Button size="sm" variant="outline" onClick={() => mut.mutate()} disabled={mut.isPending}>
        {t('admin.users.impersonate.stop')}
      </Button>
    </div>
  );
}
```

Adapt token names (`bg-warning-container`, `text-on-warning-container`) to whatever the project's brand actually exposes. If those tokens don't exist, use `bg-amber-100 text-amber-900 border-amber-300` as a fallback.
